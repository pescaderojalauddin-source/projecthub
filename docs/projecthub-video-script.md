# Сценарий видео-демонстрации ProjectHub (2–3 минуты)

> Тема ТЗ: **«Система управления проектами»** (есть в списке организаторов: «создавать, удалять, изменять проекты, а также добавлять участников»). Все нижеперечисленные сцены покрывают **все** обязательные требования + почти все опциональные, влияющие на оценку.

## Что должно быть подготовлено ДО записи

1. **Окно с приложением открыто** на `http://localhost:8080/login` (запущено через `./mvnw spring-boot:run`, демо-данные засеяны).
2. **Второе окно браузера** (или вкладка) — для Swagger UI и H2-console, чтобы не терять время на навигацию.
3. **Терминал** где-то рядом — для одного быстрого показа структуры кода и `./mvnw verify` (опционально).
4. **БД-клиент или вкладка H2-console** открытая с готовым запросом `SELECT login, password FROM users LIMIT 3;` — чтобы быстро показать BCrypt-хеши паролей.
5. **Включена светлая тема** в браузере — переключите на тёмную в кадре.
6. **Логин/пароль на буфере**: `admin` / `admin123` и `ivan` / `user123`.
7. **Закрыть** ненужные вкладки/уведомления, чтобы кадр был чистый.

### 🎬 1:30 – 2:00 — Канбан + конфетти + история (Envers)

**Кадр:** Страница проекта. Нажать «Канбан» рядом с «Новая задача».

**Что говорить:**
> «Канбан-доска: drag-and-drop через SortableJS + HTMX, статус сохраняется без перезагрузки. При перетаскивании задачи в «Готово» — конфетти-анимация. История изменений по каждой задаче через Hibernate Envers.»

**Действия:**
1. Перетащить любую карточку из «В работе» в «Готово» → запустится анимация конфетти (~2.5 с).

3. Нажать «История» → видно ревизии «СОЗДАНО → ИЗМЕНЕНО» с timestamp и снэпшотами полей (Hibernate Envers).

**Что закрывает:** Опциональное «асинхронное взаимодействие» (HTMX), ORM Hibernate, паттерны (Repository + Auditing).

### 🎬 2:15 – 2:35 — REST API (Swagger) + роли + админка

**Кадр:** Открыть в новой вкладке `http://localhost:8080/swagger-ui/index.html`.

**Что говорить:**
> «RESTful API задокументирован через OpenAPI/Swagger. Разграничение доступа по ролям — USER и ADMIN. Админка `/admin/users` доступна только админу.»

**Действия:**

2. Раскрыть `GET /api/v1/projects` → Try it out → Execute → JSON-ответ 200.
3. Переключиться на основную вкладку → кликнуть «Админка» в навбаре → таблица пользователей (27 шт.) с ролями и активностью.

**Что закрывает:** REST API, роли (ADMIN/USER), документация API.

### 🎬 2:35 – 2:50 — Безопасность: пароли в БД (BCrypt) + rate-limit

**Кадр:** Вкладка H2-console (или быстрый показ кода).

**Что говорить:**
> «Безопасность: пароли хранятся в BCrypt, rate-limit на /login и /register, защита CSRF, безопасный сидер админа.»

**Действия:**
1. Открыть `/h2-console` (под dev-профилем) → JDBC URL `jdbc:h2:mem:projecthub`, юзер `sa` → Connect.
2. Выполнить `SELECT login, password FROM users LIMIT 3;` → видны хеши `$2a$10$...` (BCrypt).
3. (Опционально) показать `/api/login` 10 раз неправильно → на 11-й 429 Too Many Requests.

**Что закрывает:** ТЗ-Тех-4 (шифрованные пароли), безопасность.

## 💡 Советы по записи

- **Длина:** уложитесь в 2:30–3:00. Если перерасход — урезайте сцены «Календарь» и «JavaMelody».
- **Озвучка:** говорите чётко и быстро (~150 слов/мин). Каждая сцена — одно ключевое предложение, остальное показывает картинка.
- **Темп:** не задерживайте курсор на пустых местах. Каждый клик должен вести к новому требованию ТЗ.
- **Запись:** OBS Studio (бесплатно), 1080p, 30 fps, формат MP4. Если есть микрофон — запишите голосовое сопровождение прямо во время скриншеринга. Если нет — добавьте субтитры или voiceover в видеоредакторе (DaVinci Resolve / CapCut / Shotcut — бесплатно).
- **Заставка:** добавьте 2-секундный титульный кадр «ProjectHub — система управления проектами / Курс: Промышленная разработка на Java / Naumen». В конце — те же титры с вашими ФИО.
- **Курсор:** включите подсветку курсора в OBS, чтобы было видно, куда вы кликаете.
- **Звук:** если используете музыку — только тихая (~10%), не отвлекающая. Лучше вообще без неё.
- **Перед стартом:** один тестовый прогон без записи — чтобы убедиться, что всё работает и не зависает (особенно H2-console и JavaMelody).
- **Один проход:** записывайте одним дублем без склеек — это выглядит цельно. Если ошибётесь — начните сначала.
